# POS-System

## Overview
POS-System is a Java-based Point of Sale (POS) application designed to manage retail operations efficiently. It includes features such as inventory management, sales processing, and OCR-based receipt handling.

## Features
- **Inventory Management**: Track and manage product stock levels.
- **Sales Processing**: Handle transactions and generate receipts.
- **OCR Integration**: Extract text from images for receipt processing.
- **Loyalty Program**: Manage customer loyalty memberships.

## Project Structure
build.xml - Build configuration file. 
manifest.mf - Application manifest file. 
src/ - Source code directory. 
possystem/ - Core POS system implementation. 
ocr/ - OCR-related functionality. 
img/ - Image assets. 
test/ - Unit tests for the application. 
build/ - Compiled classes and build artifacts. 
nbproject/ - NetBeans project configuration file

## Prerequisites
- **Java Development Kit (JDK)**: Version 8 or higher.
- **Apache Ant**: For building the project.
- **NetBeans IDE**: Optional, for development.
